# TxImhotep LLC - Enterprise Repository

Centralized management repository for TxImhotep LLC corporate operations, treasury, shared infrastructure, and product-led growth assets.

## Directory Manifest
* `treasury/` - Financial records, commercial banking applications, and capital management.
* `infrastructure/` - Core cloud provisioning and Terraform modules (`securebase-terraform`).
* `products/` - Commercial software platforms (`securebase-app`).
* `marketing/` - Go-to-market strategies, outreach campaigns, and sales collateral.
